OVERVIEW

A social space for sharing art.

Inkspire is a web-based art-sharing platform inspired by social media applications like Instagram.

Users can create accounts, customize their profiles, upload artwork, and interact with other users through likes and comments.

Django Framework

PROJECT STATUS

Built, awaiting deployment.

IN DEVELOPMENT

Inkspire is a Django-based art-sharing platform with features for user authentication, profile customization, artwork uploads, likes, and comments.

The application was developed with the intention of staying deployed on Render. However, I was unable to continue paying for the subscription, so I had to take the project offline.

The project is currently awaiting deployment on a new hosting platform. Until then, the source code remains available on GitHub.

FEATURES

More than just an artwork feed.

I built Inkspire around several connected features designed to make the platform feel like a small social network for artists.

✦

User Authentication

Users can sign up, log in, log out, and automatically access their account after signup.

✦

Profiles

Each user has a customizable profile with a profile image, bio, and uploaded artwork.

✦

Artwork Uploads

Users can upload artwork with information such as titles and descriptions.

✦

Likes & Comments

Users can interact with artwork through likes and dynamically added comments.

✦

AJAX Interactions

Likes and comments can be handled without requiring the entire page to refresh.

✦

Admin Panel

Administrators can manage users, artwork, comments, likes, and other application data.

DATA MODEL

Inkspire uses Django's built-in User model along with custom Profile, Artwork, Comment, and Like models to connect the different parts of the application.
