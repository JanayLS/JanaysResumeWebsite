# 💜 Personal Resume Website

A personal resume website built to showcase my education, technical skills, experience, and programming projects in one place.

I created this website to serve as my online resume and professional portfolio. It highlights my background in programming, the technologies I've worked with, and projects I've developed throughout my learning journey.

I wanted to create something that feels professional while still reflecting my personality through a fun, creative design.
